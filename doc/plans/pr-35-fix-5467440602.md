## Implementation discipline

**Strict fine-grained TDD** on every behavior change:

1. **RED** - write or extend the exposing test first; run it; observe the
   expected assertion failure (or compile failure) *before* touching production
   code. Record the failing assertion text in the commit body.
2. **GREEN** - smallest production change that turns that cycle's pins green.
3. **REFACTOR** - behavior-preserving cleanup only under green; no behavior
   change without a new RED.
4. Do **not** push a RED tree. A single commit may contain RED-verified tests
   plus the GREEN implementation, with local RED observations recorded in the
   commit message (same convention as PR 28 / issue #30).
5. Characterization pins for *already-correct* behavior: write first, confirm
   GREEN on arrival, then **mutation-check** (temporarily break the code,
   observe RED, revert). Record "mutation-checked" in the commit body.
6. Docs-only / roadmap / plan-status / PR-reply changes have no artificial RED;
   they land under the all-green gate, ideally in the same commit as the
   behavior they describe when user-facing.

Per-cycle gate (every commit tip):

```bash
cargo fmt --check
cargo clippy --all-targets --locked -- -D warnings
cargo test --locked --offline --lib --bins
```

No network. Do not touch `tests/s3_integration.rs` or env-gated suites.
Do not edit W25 characterization tests, walk tests, config tests, CLI, plan,
exec, or store. `Cargo.toml` / `Cargo.lock` dependency sections stay untouched

## Algorithm (normative for W187)

Replace the body of `segment_glob_matches` only. `SegmentGlob::from` stays `seg.split('*').map(str::to_string).collect()`.

Invariant from compile: a glob segment always contains at least one `*`, so `parts.len() >= 2`. Pattern-level `**` reject means no two stars are adjacent in the *raw pattern string*; interior `parts` entries are therefore never adjacent-empty from `**`. A segment that is exactly `*` is `parts == ["", ""]`.

Correct non-crossing glob over one segment (literal parts joined by `*`, anchored):

```text
match_parts(seg, parts):
  # parts = [p0, p1, ..., pN], N >= 1; stars sit between consecutive parts
  # p0 must be a prefix of seg (anchor). Empty p0 <=> leading *.
  if not seg.starts_with(p0): return false
  return match_after_star(seg[p0.len()..], parts[1..])

match_after_star(seg, parts):
  # One * has just been "entered". parts is the remaining literals
  # (and further stars between them).
  if parts is [last]:
      # Final literal after the last star.
      # Empty last <=> trailing *; otherwise seg must end with last.
      return last is empty or seg.ends_with(last)
  # parts = [lit, ...rest] with at least one more star after lit.
  # Empty lit cannot appear here from `**` (rejected). If it did, treat as
  # another star: match_after_star(seg, rest).
  if lit is empty: return match_after_star(seg, rest)
  # Try each occurrence of lit in seg (backtracking); UTF-8 safe advance.
  search from byte 0:
      find lit in seg[from..]
      if none: return false
      pos = from + rel
      if match_after_star(seg[pos+lit.len()..], rest): return true
      advance `from` by one char at `pos` (char_indices / chars().next().len_utf8)
  return false
```

Properties this locks:

| pattern | segment | result | why |
| ------- | ------- | ------ | --- |
| `b*` | `ab` | false | `p0="b"` not a prefix |
| `workspace*` | `xworkspace` | false | same anchor |
| `workspace*` | `my_workspace` | false | same anchor |
| `workspace*` | `workspace` | true | prefix + trailing `*` |
| `workspace*` | `workspaces` | true | trailing `*` consumes `s` (correct glob; not a false friend) |
| `a*a` | `baa` | false | anchor |
| `a*a` | `aaa` | true | after first `a`, final `a` via `ends_with` |
| `a*b` | `abxb` | true | after `a`, final `b` via `ends_with` |
| `a*bc` | `abcbc` | true | after `a`, final `bc` via `ends_with` (not first `find`) |
| `*a` | `baa` | true | leading `*` + final `ends_with("a")` |
| `*a` | `aaa` | true | same |
| `a*a*a` | `aaaaa` | true | backtracking / chained after-star |
| `pre*mid*suf` | `premidXsuf` | true | existing pin |
| `*` | any segment incl. empty | true | `parts=["",""]` -> prefix `""`, trailing `*` |

Do **not** implement via `Regex` or by allocating a joined pattern string per query. Prefer a small private recursive helper or an explicit stack; both are fine under std-only. Keep the function pure and panic-free on empty `parts` via `debug_assert!(!parts.is_empty())` at entry (nit from review); if `parts` were ever empty, return `seg.is_empty()` rather than `unreachable!` so query paths never abort a sync (belt and suspenders).

**Goal:** `exact_segs_match` and `dir_prefix_segs_match` no longer `collect::<Vec<_>>()` on each query. Observable behavior identical.

**RED form:** none required for pure refactor if W186/W187 pins already cover ExactSegs / DirPrefixSegs. Still run the full ignore suite before and after. Optional characterization is already present (`foo/*/bar`, `cache/*/`, workspace star path form).

**GREEN shape (illustrative):**

```rust
fn exact_segs_match(key: &str, segs: &[Segment]) -> bool {
    if key.ends_with('/') {
        return false;
    }
    let mut parts = key.split('/');
    for seg in segs {
        let Some(ks) = parts.next() else {
            return false;
        };
        match seg {
            Segment::Exact(s) if s.as_str() != ks => return false,
            Segment::Glob(g) if !segment_glob_matches(ks, g) => return false,
            _ => {}
        }
    }
    parts.next().is_none()
}

fn dir_prefix_segs_match(key: &str, segs: &[Segment]) -> bool {
    let folder = key.ends_with('/');
    let body = key.strip_suffix('/').unwrap_or(key);
    let mut parts = body.split('/');
    for seg in segs {
        let Some(ks) = parts.next() else {
            return false;
        };
        match seg {
            Segment::Exact(s) if s.as_str() != ks => return false,
            Segment::Glob(g) if !segment_glob_matches(ks, g) => return false,
            _ => {}
        }
    }
    // Equal segment count requires a folder key so a file equal to the dir
    // path without slash does not match (same rule as before).
    let has_more = parts.next().is_some();
    if !has_more && !folder {
        return false;
    }
    // Drain unused: has_more already peeked one; further segments are fine
    // (prefix match). No need to consume the rest.
    true
}
```

Pin comment above the helpers: `// Match path is collect-free so #32/#33 can call matches per entity without per-query Vec churn.`
